GenMeta Help

About GenMeta

GenMeta is a desktop application that uses AI to generate metadata for your images and videos. This tool automatically creates titles, descriptions, and keywords for your media files, making them more discoverable and SEO-friendly.

Supported formats: JPG, PNG, EPS (images) and MP4, MOV. For videos, metadata is saved as external JSON and TXT files alongside the video.

Getting Started

  • Select Files - Choose individual image or video files to process
  • Select Folder - Choose a folder containing multiple media files
  • Generate - Process the selected media files to create metadata
  • Stop - Cancel the current processing operation
  • Clear - Reset the application and clear all results

Settings

  • API Configuration - Set up your Gemini API key for image processing
  • AI Parameters - Customize title length, description length, keyword count, and add positive/negative keywords
  • System Configuration - Adjust system-level settings
  • File Options - Configure file handling options like creating JPG copies of EPS files

Working with Results

  • Save All Changes - Apply all metadata changes to the original image files
  • Export CSV - Export all metadata to a CSV file
  • Bulk Edit - Edit metadata across all processed images at once
  • Rename Files - Rename files based on their title or description
  • Retry Failed - Retry processing for any failed images
  • Click on individual result cards to view and edit metadata before saving

Bulk Edit Features

  • Keywords - Add common keywords to all images at the start, end, or custom position
  • Title - Insert or replace text in all titles, or update titles from descriptions
  • Description - Insert or replace text in all descriptions, or update descriptions from titles

Updates

  • Check Updates - Manually check for application updates
  • Download Update - Download a new version when available
  • Install Update - Install a downloaded update (application will restart)

Note: When you click "Install Update", the button will be disabled and show "Preparing for install..." while the update is being prepared. The application will restart automatically to complete the installation.

  • Use your own Gemini API key for customized results
